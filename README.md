# Protótipo-do-site-JÁ-Te-Conto-Atualizações-do-João-Pedro-
Qualquer atualização que eu fizer às páginas do site JÁ Te Conto será salva nesse repositório.

# Últimas atualizações:
 1. Foi feita a base da página de perfil.

 2. Essa base foi dividida em 3 seções que serão todas preenchidas depois.
      - div "lado-banner", que é a parte verde de cima da caixa de perfil.
           - section "foto-perfil", que é a foto de perfil.
           - section "texto-banner", que é para os texto logo a direita da foto de perfil.
           - section "biografia", que é a biografia, logo a direita do texto-banner.

      - div "lado-conta", que é todas as informações da conta fora do banner, exceto o botão de configurações.
           - section "estatisticas", que é para as estastísticas pessoais como livros lidos, livros ainda lendo, etc.
           - section "estante", que é especificamente para os livros que o usuário possui.

      - div "configuracoes", que é o botao de configurações.
      
 3. Foi feito um protótipo do banner da página de perfil. **FEEDBACK DO DESIGN VISUAL AINDA NECESSÁRIO**

 4. Imagens foram adicionadas na pasta assets para serem usadas na página de perfil.
      - ButtonEmoji1, que é usado no botão de qual livro o usuário está lendo atualmente.
      - ButtonEmoji2, que é usado no botão de mudar a biografia.
      - ButtonEmoji3, que é usado no botão de configurações de conta.
      - Placeholder, que é a foto de perfil.

 5. O arquivo /assets/style e a sua única menção em login.html foram renomeados para /assets/login_style, para manter a nomenclatura consistente com os outros arquivos .css.
      - **NÃO SUBSTITUA A SUA CÓPIA DO ARQUIVO COM A MINHA. EM VEZ DISSO, SIMPLESMENTE RENOMEIE A SUA PRÓPRIA CÓPIA E A SUA ÚNICA MENÇÃO EM login.html. FAÇA ISSO PARA QUE VOCÊ NÃO PERCA QUAISQUER MUDANÇAS QUE VOCÊ POSSA TER FEITO A ESSE ARQUIVO.** Você pode renomear arquivos e pastas clicando com botão direito do mouse em cima do arquivo e depois em renomear, ou simplesmente clicando F2 em cima dele.
